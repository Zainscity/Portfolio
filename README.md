# Modern Engineering Portfolio

A premium, minimalist portfolio focused on **Next.js** and **Agentic AI Orchestration**. Built with a focus on performance, accessibility, and clean aesthetics.

## 🚀 Tech Stack

- **Framework:** [Next.js 15+](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
- **Forms:** [React Hook Form](https://react-hook-form.com/) with [Zod](https://zod.dev/) validation
- **Deployment:** [Vercel](https://vercel.com/)
- **Form Handling:** [Web3Forms](https://web3forms.com/)

## ✨ Key Features

- **Interactive UI:** Smooth entrance animations and hover effects using Framer Motion.
- **Agentic AI Focus:** Specifically designed to showcase LLM orchestration and MCP server projects.
- **Glassmorphism:** Modern UI components with backdrop blur effects and dynamic gradients.
- **Dark Mode Support:** Fully responsive and optimized for both light and dark themes.
- **Optimized Performance:** High Core Web Vitals scores using Next.js Server Components.

## 📁 Project Structure

- `src/app`: Next.js App Router pages and layouts.
- `src/components/sections`: Main website sections (Hero, About, Projects, etc.).
- `src/components/ui`: Reusable UI primitives.
- `src/data`: Static project and configuration data.
- `public/`: Static assets like images and the resume PDF.
